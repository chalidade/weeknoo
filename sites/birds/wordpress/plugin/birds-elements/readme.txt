Editorial toolkit for the Birds magazine: Elementor widgets and shortcodes, contributor profiles, article settings and free vs member access.

== Description ==

**Elementor widgets** (panel category “Birds”): Chart (column, bar, line, donut), Pull Quote, Key Takeaways, Photo & Quote Carousel, Action Table, Author & Experts, Member Gate, Article Grid, Featured Hero, Membership Banner, Series Sections, Article Header.

**Shortcodes** for the block or classic editor — the same components: see Settings → Birds.

**Contributors**: a Contributors menu for authors, editors and interviewed experts (portrait, designation, company, bios, LinkedIn, company website).

**Article settings** on every post: access tier (Free / Member), kicker, hero (image or looping video), read time, key takeaways, written by, experts interviewed.

**Member access**: members are WordPress Subscribers. Joining is free and instant from the unlock card; member articles are cut on the server for signed-out readers, so the hidden part never reaches the browser, the feed or the REST API.

**Demo content**: Settings → Birds → Import demo content (10 sample briefings; people, companies and figures are fictional).
