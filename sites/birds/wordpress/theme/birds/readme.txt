Editorial magazine theme for Birds — Baugment’s Insights, Research, and Discoveries.

== Description ==

* Transparent one-row header; series dropdowns built from your categories (or any menu at Appearance → Menus).
* Magazine home: featured video/image hero, latest insights with series filter chips, membership banner, one section per series — all toggled and worded in Appearance → Customize → Birds.
* Zero-sidebar article page: reading progress, hero image or looping video, author and expert profiles, key takeaways, Listen / Save / Share / Download PDF.
* Palette (Dark Blue, Royal Blue, Light Grey) adjustable in the Customizer.
* Works with Elementor: pages built with Elementor get the full width; Elementor Pro header/footer/single locations are registered.

Install the companion plugin **Birds Elements** for charts, contributors, member access and the Elementor widgets.
